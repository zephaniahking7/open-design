Do not blindly paste every component.
Use the design language and useful interaction patterns, but adapt them safely into the existing codebase.

Reliability beats visual excess.
If a component causes performance risk, import issues, framework mismatch, or bundle bloat, recreate the visual effect more lightly using existing React, CSS and Tailwind.

TECHNICAL RULES:
- This is React + Vite, not Next.js.
- Do NOT install Next.js.
- Convert any next/image usage into standard React/Vite-safe code.
- Do not add unnecessary libraries.
- lucide-react and framer-motion are acceptable if already installed or truly needed.
- Avoid GSAP/WebGL/shader overload unless lazy-loaded or clearly isolated.
- Preserve /api/render SSE.
- Preserve /api/leads.
- Preserve /studio and its existing gate.
- Preserve backend routes.
- Preserve database schema.
- Preserve rate limits.
- Preserve error reporting.
- Preserve current lead flow.
- Do not modify middleware ordering.
- Do not broaden the studio into CRM, invoicing, file storage, portal, or project management.
