HUASHU DESIGN — DIRECTION LAYER

STYLE PRINCIPLE:
Minimal luxury with cultural undertone.

CORE TRAITS:
- calm, confident, intentional
- high clarity, low noise
- premium spacing and typography
- subtle warmth (Brixton / JA influence), never loud

COLOUR GUIDANCE:
- base: soft cream / off-white
- primary accent: deep green (tile green)
- highlight: warm gold / rust
- avoid neon, avoid pure black/white contrast

TYPOGRAPHY:
- modern sans-serif
- strong hierarchy
- generous spacing
- avoid cluttered text blocks

LAYOUT:
- clean sections
- strong hero presence
- breathing space between elements
- no unnecessary cards or nested boxes

INTERACTION:
- smooth, subtle
- no aggressive animations
- focus on clarity and flow

ANTI-PATTERNS:
- generic AI gradients
- over-styled UI
- excessive shadows
- crowded layouts

GOAL:
Every output should feel intentional, premium, and culturally aware.
